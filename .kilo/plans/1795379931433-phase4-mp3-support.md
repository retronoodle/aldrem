# Phase 4 — MP3 support (minimp3)

## Goal

MP3 files play through the same engine as WAV: streaming decode, duration, pause/stop,
and seek, all behind the existing `track_*` interface. Builds on `3aade1a` (Phase 3).

## Verified context

- `track.h` is the whole interface: `track_open`, `track_decode_chunk`, `track_seek`,
  `track_close` (`src/track.h:20-30`). Only `playback.c` calls them; callers need no change.
- Today `track_open` **is** the WAV implementation in `src/track_wav.c:39-92`. There is no
  dispatcher, and the three other public `track_*` symbols are also defined there
  (`track_wav.c:94-138`), so a second implementation cannot coexist without a factory/vtable.
- `playback.c` is format-agnostic: it builds `SDL_AudioStream` from `info.src_spec` to the
  fixed float32 device (`src/playback.c:308-310`), takes duration from
  `total_frames / src_spec.freq` (`playback.c:458-460`), and seeks by source frame
  (`playback.c:74-85`, `playback.c:304`). **No playback.c or main.c changes are expected.**
- `track_seek` is absolute in source frames; `playback_seek` already clamps and rebuilds the
  session (`playback.c:521-561`), so MP3 seek only has to implement `track_seek`.
- CLI loading already exists (`src/main.c:261-265`); drag-and-drop/Open are Phase 5.
- Build: `SRC` in `Makefile:5`; `-Ivendor` is already there (`Makefile:2`).
- No `ffmpeg`/`lame` on this machine; `afinfo`/`afplay`/`afconvert` are available. A real MP3
  exists at `~/Music/Music/Media.localized/Music/Unknown Artist/Unknown Album/His Honor_gaudiolab_drum.mp3`.

## Decisions

- **Use minimp3 core only** (`mp3dec_init` / `mp3dec_decode_frame`), not `minimp3_ex`. Matches
  the PRD's streaming + byte-offset seek design; keeps vendored surface to one header.
- **Add a tiny vtable + dispatcher**: new `src/track.c` owns `track_open` (detection/dispatch)
  and the three public functions; implementations expose `track_wav_open` / `track_mp3_open`
  and fill a `TrackOps` vtable. No change to `track.h`.
- **Detection:** extension first (`.wav`/`.mp3`, case-insensitive); if the extension is not one
  of those, sniff the first 12 bytes: `RIFF` → WAV; `ID3` or `0xFF` + valid MPEG sync/layer
  bits → MP3. Unknown → error naming both formats. No cross-fallback for mislabelled files.
- **Duration:** first frame gives hz/channels/bitrate. Sample up to 64 frames; constant bitrate
  → CBR estimate from audio byte length / bitrate. Variable → one full header-only scan
  (`mp3dec_decode_frame(..., pcm=NULL, ...)`) summing samples per channel for an exact frame
  count. Result is cached for the life of the loaded track only (no disk cache).
- **Seek:** seconds → byte offset by linear average bitrate
  (`data_start + (data_end-data_start) * frame / total_frames`), `fseek`, reset minimp3 and
  input buffers, resync by feeding chunks. ±1 s accepted per PRD; VBR may be worse locally.

### 2. Introduce the track dispatcher

New `src/track_internal.h` (not part of the public API):

```c
#include "track.h"
typedef struct TrackOps {
    int  (*decode_chunk)(Track *, Uint8 *, int);
    int  (*seek)(Track *, Uint32);
    void (*close)(Track *);
} TrackOps;
typedef struct { const TrackOps *ops; } TrackBase; /* first member of every Track impl */
Track *track_wav_open(const char *, TrackInfo *, char *, size_t);
Track *track_mp3_open(const char *, TrackInfo *, char *, size_t);
```

New `src/track.c`:

- `track_decode_chunk/track_seek/track_close` become one-line dispatchers via
  `((TrackBase *)t)->ops`; `NULL` still returns `-1` for decode/seek, no-op for close.
- `track_open(path, info, err, errlen)`:
  1. validate args;
  2. `ext_is(path, ".wav")` → `track_wav_open`; `ext_is(path, ".mp3")` → `track_mp3_open`;
  3. otherwise `sniff(path, ...)` (fopen + 12-byte read) and dispatch;
  4. unknown/open-failure → human-readable error (e.g. `unsupported file type: expected .wav or .mp3`),
     return `NULL`. Implementations still own their own error strings.

`ext_is` compares the last `.` case-insensitively (no POSIX-only `strcasecmp` needed).

### 4. MP3 implementation — new `src/track_mp3.c`

At the top, in this TU only:

```c
#define MINIMP3_IMPLEMENTATION
#include "minimp3.h"
```

If the vendored header produces warnings under `-Wall -Wextra`, wrap the include in
`#pragma clang diagnostic push/ignored` (or set the flag on `src/track_mp3.o` only). Do not
edit the vendored file. Target is zero warnings.

State (`struct Track { TrackBase base; ... }`):

- `FILE *fp`, `long file_size`, `long data_start`, `long data_end`.
- `Uint32 hz`, `int channels`, `Uint32 total_frames`.
- `mp3dec_t dec`.
- Compressed-input buffer `Uint8 in[32*1024]`, `int in_len, in_off`, `int at_eof`.
  Keep **≥4 KiB headroom** (`MAX_FREE_FORMAT_FRAME_SIZE` is 2304) so no frame is split at a
  refill boundary: refill/compact whenever `in_len - in_off < 4096 && !at_eof`.
- Decoded-frame buffer `mp3d_sample_t pcm[MINIMP3_MAX_SAMPLES_PER_FRAME]` (int16,
  interleaved), `int pcm_valid`, `int pcm_off` (samples per channel).

`track_mp3_open`:

1. `fopen`; `fseek/ftell` file size.
2. **ID3v2:** if the first 3 bytes are `ID3`, parse the 10-byte header's syncsafe size
   (`bytes 6..9`, footer adds 10 when byte 5 bit 0x10 is set); `data_start = 10 + size (+10)`,
   clamp to file size. Otherwise `data_start = 0`.
3. **ID3v1:** if the last 128 bytes start with `TAG`, `data_end = file_size - 128`; else
   `data_end = file_size`. (APEv2 at the tail is out of scope; it only adds a tiny CBR
   duration overestimate and decodes as trailing garbage → clean EOF.)
4. Validate `data_end > data_start`, else error.
5. Fill the input buffer from `data_start`, `mp3dec_init`, decode the first frame with
   `mp3dec_decode_frame`. Require `ret > 0` and sane `fi.channels/hz/layer`; otherwise error
   `cannot decode MP3 '%s'`. This establishes `hz`, `channels`; reject later frame-to-frame
   hz/channel changes (return `-1` from decode).
6. Determine duration:
   - continue header scan (`pcm=NULL` returns samples per channel, `fi.frame_bytes` gives
     consumed bytes) for up to 64 frames, collecting `fi.bitrate_kbps`;
   - constant → CBR: `seconds = (data_end-data_start)*8 / (bitrate*1000)`;
     `total_frames = lround(seconds*hz)`;
   - variable or too few frames → full header scan from `data_start`, sum returned samples
     per channel → exact `total_frames`;
   - reset `fseek(data_start)`, `dec`, `in_len/in_off`, `pcm_valid/pcm_off`, `at_eof`.
7. Fill `info->src_spec = { .format = AUDIO_S16SYS, .channels, .freq = hz }`
   (zero the rest) and `info->total_frames`.

`track_mp3_decode_chunk(t, dst, cap)`:

- Whole-frame loop: while output bytes `< cap`, if `pcm_off == pcm_valid`, call the internal
  `next_frame()`; on 0 → return bytes written so far (EOF), on -1 → return -1.
- Copy `min(pcm_valid-pcm_off, (cap-written)/(2*channels))` interleaved frames.
- `next_frame()`:
  - refill/compact when headroom is low;
  - call `mp3dec_decode_frame(&dec, in+in_off, in_len-in_off, pcm, &fi)`;
    always advance `in_off += fi.frame_bytes` (it is set even on 0);
  - `ret > 0` → verify hz/channels unchanged, set `pcm_valid = ret`, `pcm_off = 0`, return 1;
  - `ret == 0` → if `fi.frame_bytes == 0` and `at_eof`, return 0; otherwise refill and keep
    scanning (this is how ID3/garbage/tags are skipped and the stream resyncs);
  - guard against zero progress when not at EOF (refill must make progress or return 0).

`track_mp3_seek(t, frame)`:

- Clamp `frame` to `total_frames`; `offset = data_start + (long)((double)(data_end-data_start)
  * frame / total_frames)` (guard `total_frames == 0`).
- `fseek(offset)`, `mp3dec_init`, clear buffers/pcm/at_eof. Next decode call resyncs.
- Return `0` (or `-1` on fseek failure).

`track_mp3_close`: `fclose`, `free`.

## Edge cases / failure modes

- **Truncated MP3:** decode reaches EOF mid-frame → `track_decode_chunk` returns 0 → decoder
  thread flushes and stops at end of audio. No crash, no hang.
- **Corrupt MP3:** no valid first frame → `track_mp3_open` fails, `playback_load` surfaces the
  error label. Corruption later is skipped by frame resync; if nothing valid remains, clean EOF.
- **Empty/tiny file, no audio after tags:** open error (`cannot decode MP3`).
- **ID3v2 with album art:** parsed and skipped by size at open, not scanned byte-by-byte.
- **hz/channels change mid-file:** `decode_chunk` returns `-1`; session stops cleanly.
- **Seek to end:** session starts, immediately EOFs, existing `playback` path resets to STOPPED
  at 0:00.
- **Back-to-back WAV/MP3:** engine reuses the audio device; `playback_load` only rebuilds the
  track/stream (`playback.c:432-466`). UI test waits for Phase 5; verify structurally now.
- **Duration > ~27 h** exceeds `Uint32 total_frames`; accepted (same limit as WAV path).

## Risks

- **First-frame bitrate ≠ average** on CBR with unusual headers: mitigated by sampling 64
  frames; residual duration error is small.
- **VBR full scan cost:** header-only parse, one-time per load; acceptable and not persisted.
- **VBR seek accuracy:** linear byte mapping is approximate; PRD accepts ±1 s, but dense VBR
  passages may be slightly worse. Explicitly out of scope to build a VBR index.
- **minimp3 warnings:** contain them at the include site, never by editing `vendor/`.
- **Vendored header churn:** pin the commit SHA in `VENDORED.md`.

## Out of scope

- `minimp3_ex`, sample-accurate VBR seeking/index, gapless/LAME delay trimming.
- Persistent duration cache on disk, APEv2 tag trimming.
- In-app Open/file browser and drag-and-drop (Phase 5); volume wiring (Phase 6).
- Any UI redesign; the existing time label, seek bar, and status label are sufficient.
