# Phase C — AIFF / AIFC support

## Goal

AIFF and AIFC files (`.aiff`, `.aif`, `.aifc`) play, seek and report exact
duration through the existing `track_*` vtable, with no new dependency. Scope is
`docs/PRD-format-support.md` Phase C only.

## Verified context

- The WAV source is the template: whole file in memory, `struct Track` with
  `data/len/cursor/block_align`, `decode_chunk` clamping to whole frames, seek by
  frame index, `close` freeing the buffer (`src/track_wav.c:12-152`). Phase C says
  to reuse it.
- `SDL_LoadWAV` normalises WAV to a format SDL understands, which is why
  `track_wav.c` derives `block_align` from `src_spec`, never the header
  (`src/track_wav.c:1-5`, `:79`). The same rule applies here.
- The engine builds `SDL_AudioStream` straight from `info.src_spec`
  (`src/playback.c:308-310`), so any SDL-supported source format/freq/channels
  works without touching `playback.c`.
- `TrackInfo.codec` is copied into `PlaybackStatus.codec[8]` (`src/playback.h:17`);
  `"AIFF"`/`"AIFC"` fit. Bit depth is printed only when `> 0`
  (`src/main.c:436-442`).
- `total_frames` is `Uint32` (`src/track.h:15`); `src_frame_for` can return it
  exactly (`src/playback.c:74-85`), so seek must accept `frame == total_frames`.
- Dispatcher: `track_ext_supported` `src/track.c:69`, `sniff` `src/track.c:78`
  (12-byte buffer, enough for `FORM`+type), dispatch `src/track.c:128-156`, error
  text `:152`. Browser filter already delegates to `track_ext_supported`
  (`src/file_browser.c:195`).
- No vendored header is needed, so `vendor/VENDORED.md` stays unchanged.
- `packaging/Info.plist` already lists `public.aiff-audio`; only the `.desktop`
  file and UI copy need updating.
- Prior phases established the shape to follow:
  `.kilo/plans/1795441571933-phase-b-ogg-vorbis.md`.

## Decisions

- **Preserve the source width** in `src_spec` (confirmed choice), mirroring what
  `SDL_LoadWAV` does:
  - 8-bit → `AUDIO_S8` (AIFF 8-bit PCM is **signed**, unlike WAV's U8);
  - 16-bit BE → `AUDIO_S16MSB`, `sowt` → `AUDIO_S16LSB`;
  - 32-bit BE → `AUDIO_S32MSB`, `sowt` → `AUDIO_S32LSB`;
  - 24-bit → `AUDIO_S32SYS`, samples left-shifted to full scale (SDL has no
    24-bit format), `bits_per_sample` stays 24 exactly like FLAC
    (`src/track_flac.c:97-102`).
- **Integer PCM only** (confirmed choice): AIFF (implicitly BE) and AIFC
  `NONE`/`twos` (BE) and `sowt` (LE) at 8/16/24/32-bit. Any other AIFC
  compression type (`fl32`, `fl64`, `alaw`, `ulaw`, `ima4`, `MAC3`, …) fails open
  with a message naming the 4-character type.
- **Mono/stereo only**, matching FLAC and Vorbis (`track_flac.c:72-77`,
  `track_ogg.c:76-81`).
- **`codec`** is `"AIFF"` for `FORM … AIFF`, `"AIFC"` for `FORM … AIFC`.
- **Two-pass chunk scan**: first pass walks chunk headers (seeking over
  payloads) collecting `COMM` and `SSND`; second pass reads the audio. This makes
  chunk order irrelevant and avoids trusting `FORM`'s size field.
- **Chunks are validated against the real file size**, not the container's size
  fields; iterate with 8-byte headers plus even-byte padding.
- **Truncation fails open**: if the declared `SSND` payload runs past EOF, fail
  with `truncated AIFF '<path>'` (PRD req 5). Metadata inconsistencies that are
  not truncation (declared `numSampleFrames` larger than the data carries) clamp
  to the data and `SDL_Log` once, so the audio still plays.
- **`numSampleFrames` is authoritative** for duration when sane; if it is 0,
  derive from the SSND size; if that is 0 too, fail.
- **In-memory buffer only** (`malloc`, not `SDL_LoadWAV`), with a small staging
  buffer for 24-bit conversion so a 24-bit file never needs a second full copy.

## Tasks

### 1. `src/track_aiff.c`

Header comment describing: FORM/COMM/SSND, big-endian PCM, `sowt`, 24-bit
widening to S32.

```c
struct Track {
    TrackBase base;
    Uint8  *data;
    Uint32  len;          /* bytes in src_spec format */
    Uint32  cursor;
    Uint32  block_align;  /* derived from src_spec, never from COMM/SSND */
};
```

Static helpers:

- `be16(p)`, `be32(p)` — assemble from `const Uint8 *` (no casts/alignment
  assumptions).
- `parse_extended80(const Uint8 *p, double *out)` — 80-bit IEEE extended
  (1 sign, 15-bit exponent bias 16383, 64-bit mantissa with explicit integer
  bit): `ldexp((double)mantissa, exp - 16383 - 63)`. Reject sign set, exponent 0
  with mantissa 0, and non-finite results.
- `read_exact(FILE *, void *, size_t)`.

`track_aiff_open` steps:

1. Validate args (`invalid arguments`); `fopen`; on failure `cannot open '<path>'`.
2. Read 12 bytes: `FORM`, u32 size, form type. Accept `AIFF`/`AIFC`; otherwise
   `cannot decode AIFF '<path>'`.
3. Pass 1, starting at offset 12 until <8 bytes remain:
   - read id + u32 size;
   - `COMM`: require `size >= 18`; read `min(size, 22)` payload bytes
     (channels BE16 at 0, `numSampleFrames` BE32 at 2, `sampleSize` BE16 at 6,
     rate extended80 at 8..17; for AIFC require `size >= 22` and read the
     compression type at 18..21). Skip the rest of the chunk. Never read 22
     bytes when the chunk is only 18.
   - `SSND`: require `size >= 8`; read `offset` (BE32) and `blockSize` (BE32;
     informational only); record `data_pos = payload_pos + 8 + offset` and
     `data_declared = size - 8 - offset`. Reject `offset > size - 8`.
   - anything else: skip.
   - Advance `8 + size + (size & 1)`; stop cleanly on EOF. First valid
     `COMM`/`SSND` wins; duplicates are skipped.
4. Require `COMM` and `SSND`; missing → `cannot decode AIFF '<path>'`.
5. Resolve format:
   - `AIFF` → BE PCM; `AIFC` `NONE`/`twos` → BE PCM; `AIFC` `sowt` → LE PCM;
     other AIFC types → `unsupported AIFC compression '<4cc>' in '<path>'`.
   - `sampleSize` 8/16/24/32 → `AUDIO_S8` / `AUDIO_S16MSB|LSB` /
     (`AUDIO_S32SYS`, widen) / `AUDIO_S32MSB|LSB`. Other widths →
     `unsupported AIFF bit depth %u in '<path>'`.
   - channels must be 1 or 2; rate parsed from the extended80 and rounded to int,
     accepted in `[1, 384000]`; else `unsupported AIFF format in '<path>'`.
6. Determine the bytes actually present: `data_avail = data_declared`, clamped to
   real EOF (`ftell` after seeking to end, or a short read). If it is shorter
   than `data_declared` → `truncated AIFF '<path>'`.
7. `frame_bytes_src = (sampleSize/8) * channels`;
   `frames = data_avail / frame_bytes_src`. If `numSampleFrames != 0`:
   `frames = min(frames, numSampleFrames)` and, when `numSampleFrames >
   data_avail / frame_bytes_src`, log once. If `numSampleFrames == 0` use the
   derived value. `frames == 0` → `cannot determine AIFF length of '<path>'`.
8. Allocate the decoded buffer:
   - **8/16/32-bit**: `malloc(frames * frame_bytes_src)`, `fseek` to `data_pos`,
     then copy in chunks (e.g. 64 KiB) with `read_exact`; bytes are stored
     verbatim.
   - **24-bit**: `malloc(frames * 4 * channels)`; loop in blocks of ~4096 frames,
     `read_exact` into a `Uint8 tmp[4096 * 3 * 2]` slot, then write native S32:
     - BE: `v = p[0]<<16 | p[1]<<8 | p[2]`;
     - LE (`sowt`): `v = p[0] | p[1]<<8 | p[2]<<16`;
     - sign-extend (`v & 0x800000 ? v |= 0xff000000`), then write `v << 8` as a
       `Uint32` (unsigned shift; no UB).
9. `block_align = (SDL_AUDIO_BITSIZE(fmt) / 8) * channels` (4·ch for 24-bit);
   set `len = frames * block_align`, `cursor = 0`, `base.ops`.
10. Fill `info`: `memset(&info->src_spec, 0, …)`, format/freq/channels,
    `total_frames = frames`, `codec = "AIFF"/"AIFC"`,
    `bits_per_sample = (int)sampleSize`.
11. Failure path: `fclose`, free any buffer, `snprintf` the message to `err`,
    return `NULL`.

`decode_chunk`, `seek`, `close`: copy `src/track_wav.c:108-152` with `free(t->data)`
instead of `SDL_FreeWAV`. `seek` clamps to `len / block_align`, so seeking to
`total_frames` is a clean EOF.

## Edge cases / failure modes

- **FORM size wrong**: ignored; chunk walk is bounded by real EOF, so a lying
  size cannot read out of bounds or loop.
- **Zero-length / odd-sized chunks**: always advance at least `8 + (size & 1)`,
  so no infinite loop.
- **COMM after SSND**: works because pass 1 only records positions.
- **AIFC `NONE`** is valid and treated exactly like AIFF (BE).
- **8-bit signedness**: AIFF/AIFC 8-bit is signed; using `AUDIO_U8` would play as
  noise. `bits_per_sample` is 8.
- **24-bit sign extension**: unsigned arithmetic only (`Uint32 v`), shift-left 8
  to full scale; negative samples must stay negative.
- **`sowt` + 24-bit**: little-endian assembly, same widening.
- **Declared `numSampleFrames` > real data**: clamped to data, logged once, plays
  fully.
- **Declared `numSampleFrames` < real data**: extra bytes ignored.
- **Truncated SSND payload**: open fails with `truncated AIFF …`; no partial
  session is created, so the currently playing track is untouched
  (`src/playback.c:438-449`).
- **Sample rate of 0, negative, or absurd**: rejected at open; no divide-by-zero
  in the engine's duration maths.
- **>2 channels**: rejected at open.
- **Extension is authoritative**: a mislabelled file (e.g. MP3 named `.aiff`)
  fails loudly at the AIFF parser, per PRD req 1.
- **Memory**: one buffer of decoded size (4 B/sample for 24-bit, source size
  otherwise) plus a 24 KiB stack staging block; freed in `close`. Large AIFFs pay
  the same whole-file cost as WAV.
- **Threading**: the track buffer is read-only after open; seeking is index
  arithmetic. No shared state beyond what WAV already has.

## Risks

- **16/32-bit big-endian playback depends on SDL_AudioStream's endian
  converters.** SDL2 supports MSB↔native conversion for 16/32-bit, so this should
  be a straight pass-through; if a fixture reveals a problem, the fallback is to
  normalise BE formats to `AUDIO_S16SYS`/`AUDIO_S32SYS` during the copy (same
  shape as the 24-bit path) without touching `playback.c`.
- **Hand-rolled extended80 conversion**: keep it integer-sample-rate oriented
  (`ldexp` + round), reject non-finite/negative, and test 44100/48000/96000.
- **Whole-file memory cost** is inherited from the WAV design; not a regression,
  documented as a limit.
- **PRD deviation**: none on behaviour. The 24-bit → S32 widening is the same
  thing `SDL_LoadWAV` does, and `bits_per_sample` still reports 24 like FLAC.

## Out of scope

- AIFC float (`fl32`/`fl64`), `alaw`/`ulaw`, `ima4`, MACE and any compressed
  AIFC; multichannel AIFF; RF64/W64; metadata; changes to `playback.c`, the
  vtable or device setup; tests/harness beyond the build and optional fixtures.
